## 📖 About
A text-based survival choice fan game set in the Arknights universe. You play as a field Catastrophe Messenger for Rhodes Island, tasked with completing observations, escorts, or survival tasks before the Catastrophe strikes.

### 🛡️ Copyright & Fanwork Disclaimer
* This is a non-commercial, non-profit fan-made work based on *Arknights*. It is not for sale, does not accept donations, and contains no advertisements. It does not represent the official stance.
* The copyrights of characters, locations, organizations, and world-building settings (Rhodes Island, Provence, Sargon, Bolívar, etc.) belong to HYPERGRYPH.
* This game does not use any official art, audio, or paid assets. The UI is built with self-made inline graphics and system fonts. If the rights holders find any content inappropriate, it will be modified or removed immediately upon contact.

### ⚙️ Technical Details
* Planning, setting, and story designed and proofread by the author; code and copywriting co-created with AI assistance under the author's guidance.
* **Single-file, offline playable, no internet required, no telemetry**; Save data is stored locally in your current browser.
